Sobre o Pyrtugues

                

                    
O Pyrtugues é uma ferramenta educacional desenvolvida para tornar o aprendizado de lógica de programação acessível e intuitivo através do português nativo.

                    
Criado por Vinicius Caracciolo (aos 12 anos de idade), o projeto remove a barreira do idioma inglês para jovens iniciantes, mantendo a lógica do Python e utilizando Python como base.
